# Проект: Unit-тесты для Booking-сервиса

## Инструкция:

Нужно папку с проектом разместить локально, из корня проекта запускать все тесты

## Установка pytest
pip3 install pytest

## Запуск всех тестов
pytest

## Запуск с подробным выводом
pytest -v

## Запуск конкретного файла
pytest tests/test_calc_price.py
